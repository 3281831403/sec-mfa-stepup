敏感操作要求再认证，可攻击者用十分钟前那次再认证的凭据就通过了提权接口：再认证凭据必须绑定具体操作与具体资源；凭据只在策略规定的短有效期内可用，且只对绑定操作有效；认证强度必须达到操作策略要求；凭据一次性使用；降级认证不得满足高等级操作；批量校验时各操作彼此独立。不变量：同一凭据不能用于两种操作；过期凭据一律拒绝。

运行公开测试：python -m pytest tests -q

接口约定：凭据是字典，包含标识、主体、操作、资源、强度、签发时间、过期时间与降级标记；存储是字典，包含当前主体、凭据表与已用标识集合；策略是字典，包含有效分钟数与所需强度。强度等级由低到高为 low、medium、high。
